Indoor lighting represents one of the largest controllable loads in the electrical consumption profile of residential, educational, and commercial buildings, yet conventional ON/OFF switching schemes remain largely insensitive to real-time occupancy and daylight conditions. This proposal presents the design and implementation plan for a Smart Adaptive Energy-Efficient Indoor Lighting System built around the ESP32 microcontroller. The system fuses occupancy data obtained from an HLK-LD2410B millimeter-wave (mmWave) radar sensor or a passive infrared (PIR) sensor with ambient-light measurements from a Light Dependent Resistor (LDR) to compute a target illumination level, which is delivered to an LED load through Pulse Width Modulation (PWM) via a MOSFET-based or dedicated LED driver stage. An embedded finite-state machine governs transitions between occupied, unoccupied, and standby states to eliminate unnecessary energy expenditure, while an optional OLED/LCD interface provides local, real-time feedback on sensor readings and system status. This document details the background, problem statement, objectives, literature-informed rationale and a step-by-step methodology covering hardware interfacing, control logic, firmware architecture, and validation procedures for realizing the proposed system.
